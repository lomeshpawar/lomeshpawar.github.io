## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/lomeshpawar/lomeshpawar.github.io.git
cd lomeshpawar.github.io
```

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```
