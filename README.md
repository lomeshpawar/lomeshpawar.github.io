# Lomesh Pawar — Personal Portfolio

> Clean, minimal, technical software developer portfolio for Lomesh Pawar (Java Backend Developer).

## 🚀 Live Site & Deployment

- **GitHub Pages:** Deploy directly by enabling GitHub Pages on `main` branch (root `/`).
- **Local Preview:**
  - Double click `index.html` in any browser, or
  - Run with Node.js: `npx serve -l 3000 .` or `npm start`
  - Run with Python: `python -m http.server 3000`

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5, ARIA accessibility attributes, JSON-LD Schema
- **Styles:** Modern CSS3 with CSS Custom Properties, Dark/Light mode theme switching, responsive design (mobile-first, tablet, desktop)
- **Script:** Vanilla JavaScript (ES6+) for theme persistence, active section tracking (IntersectionObserver), project filtering, clipboard interactions, and mobile drawer navigation. Zero external runtime dependencies.
- **Assets:** Vector SVG icons, Google Fonts (`Inter` + `JetBrains Mono`), embedded PDF resume (`Lomeshpawar.pdf`).
